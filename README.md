클립스튜디오(페인트)에서 수정한 텍스처를 클립스튜디오 모델러의 메테리얼 탭에
반복해서 넣는 작업을 자동화하는 매크로 프로그램입니다.

타이니태스크와 달리 **Alt+Tab 창 전환을 지원**합니다.
녹화 중 Alt+Tab을 누르면 키 입력 대신 "어떤 프로그램으로 전환했는지"를 기록하고,
재생할 때는 Windows API로 그 창을 직접 활성화합니다.
그래서 재생 시점에 열려 있는 창 순서가 달라져도 항상 올바른 프로그램으로 전환됩니다.

## 실행 방법

`매크로실행.bat` 더블클릭 (또는 `python tomacro.py`)

## 사용법

| 키 | 기능 |
|---|---|
| **F9** | 녹화 시작 / 녹화 중지 |
| **F10** | 재생 시작 |
| **ESC** | 재생 중지 |

1. F9를 누르고, 평소처럼 작업을 한 번 수행합니다.
   (클립스튜디오에서 텍스처 복사 → Alt+Tab → 모델러 메테리얼 탭에 붙여넣기 → …)
2. F9를 다시 눌러 녹화를 마칩니다.
3. **"현재 녹화 저장"** 버튼으로 이름을 붙여 저장합니다. (예: `메테리얼2개`, `기본30개`)
4. 다음 작업물을 열어 놓고 F10을 누르면 똑같은 작업이 재생됩니다.

## 메테리얼 개수마다 위치가 다를 때

메테리얼이 1개일 때 / 2개일 때 / …마다 클릭 위치가 달라지므로,
**레이아웃별로 매크로를 따로 녹화해서 각각 저장**해 두고,
작업물에 맞는 매크로를 목록에서 더블클릭으로 불러온 뒤 F10으로 재생하면 됩니다.

## 재생 설정

- **반복 횟수**: 매크로를 몇 번 반복할지
- **반복 간격(초)**: 반복 사이 대기 시간
- **재생 속도**: 0.5(느리게) ~ 3.0(빠르게). 붙여넣기 씹힘이 있으면 0.8 이하로 낮추세요.

## 주의사항

- 녹화할 때와 재생할 때 **창 위치·크기, 패널 배치가 같아야** 합니다.
  (클립스튜디오/모델러를 최대화 상태로 쓰는 것을 추천)
- 화면 해상도나 배율(125% 등)을 바꾸면 좌표가 어긋나므로 다시 녹화해야 합니다.
- 클립스튜디오를 "관리자 권한"으로 실행하면 매크로가 입력을 보낼 수 없습니다.
  둘 다 일반 권한으로 실행하세요.
- 재생 중 마우스를 직접 움직이면 꼬일 수 있으니 ESC로 먼저 중지하세요.

## 필요 환경

- Windows 10/11
- Python 3.x + `pynput` (`pip install pynput`)
  (배포판 `tomacro.exe`는 설치 없이 실행 가능)

## 개발 시 주의: 매크로 파일 하위 호환성 (중요)

사용자가 녹화해 둔 매크로(`macros/*.json`)는 사용자의 작업 자산입니다.
**업데이트 후에도 이전 버전에서 저장한 녹화 파일이 반드시 그대로 동작해야 합니다.**

- 매크로 파일은 `{"version": 1, "events": [...]}` 형식이며, 이벤트 종류는
  `focus` / `move` / `click` / `scroll` / `key_down` / `key_up` 입니다.
- **기존 필드의 이름·의미·구조를 바꾸거나 삭제하지 마세요.** 새 기능이 필요하면
  새 이벤트 타입이나 선택적(optional) 필드를 "추가"만 하세요.
- 형식을 바꿀 수밖에 없다면: `version` 값을 올리고, **구버전 파일을 읽어서
  자동 변환하는 마이그레이션 코드**를 반드시 함께 넣으세요.
- 릴리스 전에 이전 버전에서 저장한 json 파일을 새 버전에서 불러오기/재생까지
  테스트한 뒤 배포하세요.
